# Mission Control — Agentic OS

A local AI command centre running on Windows 10.

## What's running
- **Mission Control dashboard** — Next.js app on http://localhost:3737
- **fcc-server v3.4.3** — Free Claude Code proxy on port 8082 (Gemini Flash Lite / NVIDIA NIM)
- **Hermes** — Nous Research agent
- **Ollama** — Local model runner (gemma3:1b)

## Stack
- Next.js + Tailwind + Framer Motion
- fcc-server (free Claude Code proxy)
- Hermes agent (Nous Research)
